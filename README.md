# Teste Manual - Lista de Tarefas

Este é meu primeiro projeto de estudos em QA.

A ideia foi praticar testes manuais usando uma lista de tarefas simples.

## Site usado

TodoMVC - React:
https://todomvc.com/examples/react/dist/

## O que foi testado

- adicionar uma tarefa;
- concluir uma tarefa;
- excluir uma tarefa;
- tentar adicionar uma tarefa vazia.

## Resultado

Os 4 casos de teste foram executados e passaram.

Nenhum bug foi encontrado nesses testes.

## Arquivos

- `casos-de-teste.md` - casos executados e resultados;
- `bugs.md` - registro de bugs;
- `evidencias/` - imagens dos testes.
