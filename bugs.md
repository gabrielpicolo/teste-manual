# Registro de Bugs

Este arquivo será usado para documentar defeitos encontrados durante a execução dos casos de teste.

No momento, nenhum bug foi registrado porque os testes ainda não foram executados.

---

## Modelo de bug

Quando um problema for encontrado, copie o modelo abaixo e preencha as informações.

```text
# BUG-001 — Título curto do problema

## Caso de teste relacionado
CTXX

## Descrição
Explique de forma simples o que aconteceu.

## Passos para reproduzir
1. Acessar a página de login.
2. ...
3. ...

## Resultado esperado
Descreva o comportamento que deveria acontecer.

## Resultado obtido
Descreva o comportamento que realmente aconteceu.

## Severidade
Baixa / Média / Alta

## Evidência
Adicionar o caminho ou link da imagem salva na pasta `evidencias/`.

## Status
Aberto
```

## Como escolher a severidade neste projeto

Para este projeto de estudo, será utilizada uma classificação simples:

- **Baixa:** problema visual ou comportamento que não impede o uso principal.
- **Média:** funcionalidade apresenta problema, mas existe alguma forma de continuar usando o sistema.
- **Alta:** funcionalidade principal fica impedida de funcionar.

> A severidade pode variar conforme o contexto real de um produto. Esta classificação foi simplificada para fins de aprendizado.
