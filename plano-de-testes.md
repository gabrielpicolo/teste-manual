# Plano de Testes

## Objetivo

Testar manualmente uma tela simples de login.

## O que vou testar

- login correto;
- usuário incorreto;
- senha incorreta;
- campos vazios.

## Dados de teste

Os dados de teste definidos para este projeto estão no README.

## Status

- `PASS` - funcionou como esperado;
- `FAIL` - não funcionou como esperado;
- `NÃO EXECUTADO` - teste ainda não realizado.
